# Kodak G-4037: POLYCONTRAST IV RC Paper

Source: KODAK PROFESSIONAL POLYCONTRAST IV RC Paper, Technical Data G-4037, June 2005
(Eastman Kodak), copy at <https://125px.com/docs/paper/kodak/g4037.pdf>, retrieved
2026-10-24. Page 8, N surface (matte), KODAK POLYMAX Filters, tray-processed in DEKTOL 1:2,
60 s, 20 °C, continuous agitation. Read from the PDF's vector paths with
`tools/datasheet_curves.py` (frame 77.1,62.5,261.6,247.1; −3…1 log H, 0…3 D; legend box
163.8,187.2,249.7,225.3; white light solid, filter 1 dash 4.0, filter 3 dash 2.0, 5+ dash
6.0). Only filters 1, 3 and 5+ are published. Combined into
`data/papers/kodak-polycontrast-iv-rc-n.csv` by `tools/paper_family.py`.
